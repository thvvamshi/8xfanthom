ROOT CAUSE
The page root was using `h-full flex flex-col` causing the layout to lock strictly into the parent `<main>` container's height (100vh). The Left Column grid item aggressively utilized `overflow-hidden flex-1` which absorbed all remaining height for the recording player, isolating the transcript inside an unreachably small `overflow-y-auto` internal container.

UX DECISION
Implemented a "natural document flow" scrolling model aligned with typical modern SaaS applications. 
1. The `h-full flex` constraints were removed from the root to let the grid grow indefinitely down the page. 
2. The Player and Transcript containers were separated cleanly with an explicit structural `gap-6`, completely eliminating the nested parent flex-shrink behaviors. 
3. The Player was given a defined `aspect-video` scale to maintain a responsive but stable size footprint, ensuring it never dominates vertical space blindly.
4. The Right Column (AI Summary Placeholder) was updated with a `sticky top-6` instruction so it stays practically anchored in view as the user reads down the transcript. 
5. Backend startup logs and API interaction logs were formatted with explicit `[8xFathom]` branding to enforce cleaner operational observability without exposing sensitive URI strings.
